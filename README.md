# todolist

브라우저에서 실행하는 To Do List 웹 프로그램입니다. Google Tasks의 기능 중 외부 서비스 연동, 기기 동기화, 모바일 알림처럼 팀 프로젝트 학습 범위를 벗어나는 기능은 제외하고, 로컬에서 직접 구현할 수 있는 할 일 관리 기능을 중심으로 구성했습니다.

## 팀원 역할

- 김수현(20251530) : index.html, LLM AI api 연동(격언 생성)
- 고근호(20232028) : style.css, 모바일 반응형 UI 구현
- 박경학(20221476) : app.js, 구글계정 로그인 기능 구현
- 김주원(20251416) : README.md, 진행도 별 캐릭터 표정 변화 구현

## 업데이트 목록

- Google 계정 로그인 기능을 추가하고, Firestore를 통해 할 일 데이터를 계정별로 저장할 수 있도록 구현
- 로컬 캐시와 Google 계정 데이터를 병합하거나 백업할 수 있는 저장 흐름 추가
- Gemini API 기반 AI 코치 기능을 추가해 할 일 상태에 맞는 격언과 동기부여 문구 제공
- AI 코치 호출을 Vercel 서버리스 함수(`/api/gemini`)로 분리해 클라이언트와 API 연동 구조 개선
- 모바일 화면에서 사이드바, 계정 영역, 캐릭터 상태 카드가 자연스럽게 보이도록 반응형 UI 개선
- 진행도와 마감 상태에 따라 캐릭터 표정과 상태 문구가 바뀌도록 시각 피드백 강화
- 작업 메뉴와 목록 메뉴의 위치, 가독성, 스타일을 정리하고 열린 메뉴가 카드 위에 표시되도록 개선
- 목록 이름 변경, 목록 삭제, 첫 번째 위치로 이동, 정렬 기준 선택 기능 추가
- 완료된 할 일 삭제와 오래된 할 일 정리 기능 추가
- PWA 매니페스트, 앱 아이콘, 서비스 워커를 추가해 앱 설치와 오프라인 캐시 기반 실행 지원

## 기능

- 여러 작업 목록 만들기 및 전환
- 할 일 목록 보기
- 할 일 추가, 수정, 삭제
- 설명 추가
- 마감일 추가
- 반복 설정
- 완료/미완료 변경
- 하위 작업 추가, 삭제
- 하위 작업 완료/미완료 변경
- 브라우저 `localStorage` 저장

## 실행 방법

```bash
open index.html
```
또는 Finder/PyCharm에서 `index.html`을 브라우저로 열면 됩니다.

## 파일 구조

```text
index.html   # 웹 화면 구조
style.css    # 웹 화면 스타일
app.js       # 웹 기능과 시각화
README.md    # 프로젝트 설명
```

## 저장 데이터

작업 목록, 할 일, 설명, 마감일, 반복 설정, 하위 작업 정보는 브라우저 `localStorage`에 저장됩니다.

## 웹 시각화

- 완료율 링
- 전체, 진행중, 기한 지남 작업 수
- 오늘, 예정, 마감 없음, 기한 지남 분포 차트
- 작업 목록별 완료율 막대

## 제외한 기능

- Gmail 연동
- Google Calendar 연동
- Google Chat 연동
- 이메일을 작업으로 만들기
- 기기 간 자동 동기화
- 모바일 앱 알림
